## Design

Defence-in-depth visual: five concentric rings represent the five layers of the ransomware framework. Layer 1 (outermost) is the perimeter — email and user awareness, the first thing an attack meets. Layer 5 (innermost, red) is backup — the last line of defence, highlighted because when everything else fails it's the only thing left. The dot at the centre is what's being defended.

The labelled list on the left names each layer; the ring stack on the right shows how they relate. The metaphor: an attacker must breach every ring to reach what's inside, and when one ring fails the next one answers.

Matches article hero palette (ink #1a2420, rust #b2292e, gold #b8862f). Official ARJ logo (white variant) bottom right.
